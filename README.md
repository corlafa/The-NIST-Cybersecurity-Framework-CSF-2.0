# 🛡️ NIST Cybersecurity Framework (CSF) 2.0 Knowledge Base

ยินดีต้อนรับสู่ Repository สรุปเนื้อหา **NIST CSF 2.0** ฉบับทำความเข้าใจง่าย โดยเนื้อหาทั้งหมดเรียบเรียงขึ้นจากเอกสารมาตรฐานต้นฉบับผสมผสานกับความเข้าใจของผู้เขียน เพื่อให้เป็นแหล่งข้อมูลที่เข้าถึงง่ายสำหรับทุกคน

---

## 🎯 วัตถุประสงค์ของโปรเจกต์ (Project Objectives)

1. **เพื่อสรุปเนื้อหา:** รวบรวมใจความสำคัญจากเอกสาร NIST CSF 2.0 (NIST CSWP 29) ให้มีความกระชับและเข้าใจง่าย 
2. **เพื่อการเรียนรู้:** ใช้เป็นเครื่องมือในการทบทวนความรู้ด้าน Cybersecurity สำหรับผู้เขียนและผู้ที่สนใจ
3. **เพื่อเป็นแนวทางการประยุกต์ใช้:** อธิบายองค์ประกอบสำคัญ เช่น Functions, Categories, Subcategories และ Tiers เพื่อให้เห็นภาพการนำไปใช้งานจริงในองค์กร

เนื้อหาถูกแบ่งออกเป็นไฟล์ย่อยเพื่อให้ง่ายต่อการศึกษา ดังนี้:
