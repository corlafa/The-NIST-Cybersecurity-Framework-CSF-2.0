## 🔄 ความแตกต่างระหว่าง 1.1 และ 2.0

| หัวข้อ | Version 1.0/1.1 | Version 2.0 |
| :--- | :--- | :--- |
| **ชื่อเดิม** | Framework for Improving Critical Infrastructure Cybersecurity | NIST Cybersecurity Framework (CSF) |
| **ขอบเขต** | เน้นโครงสร้างพื้นฐานสำคัญ (Critical Infrastructure) | **ทุกองค์กร** (SMEs, NGO, รัฐ, เอกชน) |
| **ฟังก์ชันหลัก** | มี 5 ฟังก์ชัน (ID, PR, DE, RS, RC) | **เพิ่ม GOVERN (GV)** เป็นหัวใจหลัก |
| **จุดเน้น** | การป้องกันเชิงเทคนิค | นโยบาย กลยุทธ์ และการสนับสนุนจากผู้บริหาร |

## ⚙️ องค์ประกอบของ CSF 2.0 Core



### 6 ฟังก์ชันหลัก (Functions)

<details>
<summary><b>1. GOVERN (GV) - การกำกับดูแล (ฟังก์ชันใหม่!)</b></summary>
<blockquote>กำหนดกลยุทธ์ นโยบาย และการบริหารความเสี่ยงในโซ่อุปทาน (Supply Chain) พร้อมกำหนดบทบาทความรับผิดชอบที่ชัดเจน</blockquote>
</details>

<details>
<summary><b>2. IDENTIFY (ID) - การระบุ</b></summary>
<blockquote>สำรวจสินทรัพย์ (Asset Management) ข้อมูล ฮาร์ดแวร์ ซอฟต์แวร์ และประเมินความเสี่ยงเพื่อจัดลำดับความสำคัญ</blockquote>
</details>

<details>
<summary><b>3. PROTECT (PR) - การป้องกัน</b></summary>
<blockquote>จัดการ Identity และการเข้าถึง (IAM), การสร้างความตระหนักรู้ (Awareness Training) และรักษาความปลอดภัยข้อมูล</blockquote>
</details>

<details>
<summary><b>4. DETECT (DE) - การตรวจจับ</b></summary>
<blockquote>เฝ้าระวังอย่างต่อเนื่อง (Continuous Monitoring) เพื่อหาเหตุการณ์ผิดปกติและวิเคราะห์การบุกรุก</blockquote>
</details>

<details>
<summary><b>5. RESPOND (RS) - การตอบสนอง</b></summary>
<blockquote>บริหารจัดการเหตุการณ์ (Incident Management), การวิเคราะห์เชิงลึก และการสื่อสารรายงานผล</blockquote>
</details>

<details>
<summary><b>6. RECOVER (RC) - การฟื้นฟู</b></summary>
<blockquote>ปฏิบัติตามแผนกู้คืนระบบ (Recovery Plan) เพื่อให้ธุรกิจกลับมาดำเนินงานได้รวดเร็วที่สุด</blockquote>
</details>

## 📊 CSF Profiles and Tiers

### 3.1 CSF Profiles (สถานะองค์กร)
* **Current Profile:** สถานะปัจจุบันที่เราทำอยู่
* **Target Profile:** เป้าหมายที่ต้องการไปให้ถึง
* **Gap Analysis:** การวิเคราะห์ช่องว่างเพื่อวางแผนพัฒนา

### 3.2 CSF Tiers (ระดับความเข้มงวด)
1. **Tier 1: Partial** - ทำแบบเฉพาะหน้า (Ad hoc)
2. **Tier 2: Risk-Informed** - เริ่มมีการจัดการแต่ยังไม่ทั่วถึง
3. **Tier 3: Repeatable** - มีนโยบายที่เป็นทางการและสม่ำเสมอ
4. **Tier 4: Adaptive** - คล่องตัวสูง ปรับตัวตามภัยคุกคามใหม่ๆ ได้ดี

## 🤝 การสื่อสารความเสี่ยงและการบูรณาการ

NIST CSF 2.0 ออกแบบมาให้เป็น **"ภาษากลาง"** ในการคุยกัน:
* **Executives:** คุยเรื่องงบประมาณและ Risk Appetite
* **Managers:** คุยเรื่องการนำนโยบายไปปฏิบัติ
* **Practitioners:** คุยเรื่องการติดตั้งและดูแลระบบเทคนิค

**การทำงานร่วมกับ Framework อื่น:**
* **Privacy:** ใช้ร่วมกับ NIST Privacy Framework
* **AI:** ใช้ร่วมกับ NIST AI RMF เพื่อจัดการความเสี่ยงจากปัญญาประดิษฐ์
